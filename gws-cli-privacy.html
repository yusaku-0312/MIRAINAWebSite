MIRAINA Google連携ツール

GWS_CLI プライバシーポリシー

このポリシーは、MIRAINAが運用するGoogle連携ツール「GWS_CLI」に適用します。Googleアカウントとの連携によって取得するデータの取り扱いを説明します。

1. 取得するデータ

利用者がGoogleの認証画面で許可した権限と、依頼した業務の範囲で、次のデータを取得します。

  • Google Adsの広告アカウント識別情報、アカウント設定、広告の掲載結果、およびキーワード調査の集計情報。
  • Google Analyticsのプロパティ識別情報、アクセス・イベントなどの集計レポート。
  • Google Search Consoleのサイト識別情報、検索クエリ、表示回数、クリック数などの集計データ。
  • 利用者が指定するGoogleスプレッドシートの内容と、読み取り・更新に必要な識別情報。
  • Google APIへの接続に必要なOAuth認証情報。Googleアカウントのパスワードは取得しません。

2. 利用目的と操作

データは、利用者が依頼したキーワード調査、広告・サイトの分析、レポート作成、スプレッドシートの整理や更新、および接続の維持・障害対応に利用します。Google Adsの連携は情報の取得と調査に使用します。Google Sheetsへの書き込みは、利用者が依頼した範囲で行います。

3. 保存と保護

取得したデータ、分析結果、認証情報は、MIRAINAの業務用実行環境に保存します。依頼内容に応じて、指定されたGoogleスプレッドシートや業務支援サービスの履歴・成果物にも保存される場合があります。

認証情報へのアクセスを制限し、公開ページや公開リポジトリには掲載しません。Google APIとの通信には暗号化された接続を使用します。データは業務上必要な期間に限って保管し、不要になったデータは管理する保存先から削除します。

4. 外部サービスと共有

利用者がCodexなどのAI業務支援サービスで分析を依頼する場合、依頼の処理に必要なGoogleデータを、利用者の同意のもとでOpenAIなどの当該サービス提供元へ送信することがあります。送信するデータは依頼に必要な範囲に限り、認証情報は送信しません。

Googleユーザーデータを販売せず、第三者の独立した目的での利用、広告配信、信用判断のために提供しません。Google APIから取得したデータの利用および他サービスへの転送は、Google API Services User Data PolicyのLimited Use要件に従います。上記の業務処理を提供する場合、利用者が明示的に同意した場合、セキュリティ対応、または法令への対応が必要な場合に限り共有します。

5. 連携の解除と削除

利用者は、Googleアカウントの接続設定からGWS_CLIへのアクセス許可を取り消せます。解除後、取り消した権限による新たなデータ取得は行いません。

アクセス許可の取り消しだけでは、取得済みのファイルや分析結果は自動的に削除されません。MIRAINAが管理するデータの削除は下記の窓口へご依頼ください。法令上の保存義務がある情報を除き、不要な取得データと認証情報を削除します。利用者が管理するGoogleスプレッドシートや外部サービスの履歴は、それぞれの保存先でも削除が必要です。

6. ポリシーの変更

機能やデータの取り扱いを変更する際は、このページを更新します。新たな種類のデータ取得や利用目的の変更がある場合は、実施前に利用者へ説明し、必要な同意を得ます。
